# Android-приложение

Android-приложение находится в папке `android/` и работает как связанная оболочка текущей веб-платформы. Оно открывает тот же сервер, поэтому аккаунты, база данных, домашние задания, календарь и прогресс остаются общими.

## Как запустить на эмуляторе

1. Запустить backend и сайт:

```bash
docker compose up -d postgres
python backend/server.py
```

2. Открыть папку `android/` в Android Studio.

3. Запустить конфигурацию `app`.

По умолчанию Android-приложение открывает:

```text
http://10.0.2.2:5173
```

Это специальный адрес Android-эмулятора, который ведет на `127.0.0.1` компьютера.

## Как запустить на реальном телефоне

1. Компьютер и телефон должны быть в одной Wi-Fi сети.

2. Узнать IP компьютера, например `192.168.1.25`.

3. В файле `android/gradle.properties` заменить:

```properties
WEB_APP_URL=http://10.0.2.2:5173
```

на:

```properties
WEB_APP_URL=http://192.168.1.25:5173
```

4. Пересобрать и запустить приложение.

Для production лучше использовать HTTPS-домен:

```properties
WEB_APP_URL=https://your-domain.ru
```

## Что уже поддержано

- общий backend и PostgreSQL с веб-версией;
- вход в те же аккаунты;
- открытие внешних ссылок вне WebView;
- кнопка Android «назад» работает как переход назад внутри сайта;
- загрузка файлов и фотографий через `<input type="file">`;
- экран ошибки, если сервер недоступен.
